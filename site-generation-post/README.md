Генератор постов для товаров — простой сайт на Flask. Без базы данных, без нейросетей.

## Запуск

```bash
cd post-generator
pip install flask
python app.py
```

Затем откройте в браузере: http://127.0.0.1:5000

> Если порт 5000 занят (на macOS его часто занимает AirPlay Receiver),
> запустите на другом порту: `python app.py` замените в конце файла
> `app.run(debug=True)` на `app.run(debug=True, port=5055)`.

## Что делает сайт

1. Пользователь вводит название товара, описание, цену/выгоду и выбирает настроение.
2. Нажимает «Сформировать пост».
3. Сайт собирает пост по шаблону: заголовок → основной текст → польза → СТА → хэштеги.
4. Кнопка «Скопировать пост» копирует текст в буфер обмена.

Если описание не заполнено — сайт покажет «Добавьте описание товара».

## Где менять стиль

- `app.py` — блок «НАСТРОЙКИ СТИЛЯ» в начале файла: тон, эмодзи, заголовки, СТА, хэштеги, длина текста.
- `voice.md` — описание правил стиля постов.
