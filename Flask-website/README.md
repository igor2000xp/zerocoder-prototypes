# AI-дайджест для новичков

Небольшой конверсионный сайт на Flask: десять карточек о нейросетях,
Claude Code, промптах, первых проектах и типичных ошибках.

## Запуск

```bash
# 1. Создай виртуальное окружение (один раз)
python3 -m venv .venv

# 2. Активируй его
source .venv/bin/activate

# 3. Установи Flask
pip install -r requirements.txt

# 4. Запусти сайт
python app.py
```

Открой в браузере: **http://127.0.0.1:5000**

> На macOS команда `python` может называться `python3` — подойдёт любая.
> Порт выбирается автоматически: если 5000 занят (например, системным
> AirPlay Receiver на macOS), адрес напечатается в терминале — обычно
> это http://127.0.0.1:5001.

## Если сайт отвечает «Access denied» (HTTP 403)

Это не ошибка сайта. На macOS порт 5000 слушает системный AirPlay Receiver
(функция AirDrop и Handoff), и пока Flask не запущен — запросы попадают на него.
Решения:

1. Запусти сайт: `python app.py` — и обнови вкладку.
2. Либо отключи приёмник AirPlay: «Системные настройки → Основные →
   AirDrop и Handoff → Приёмник AirPlay».

## Что внутри

```
app.py                Flask-приложение: читает JSON и отдаёт страницу
content.json          10 карточек: заголовок, описание, ссылка, теги
templates/index.html  HTML-шаблон страницы
static/style.css      оформление, анимации и адаптив
static/script.js      поиск, фильтры, наклон карточек, форма
requirements.txt      зависимости проекта
```

## Как добавить карточку

Открой `content.json` и добавь новый объект в массив `cards`:

```json
{
  "title": "Заголовок",
  "description": "Короткое описание материала.",
  "link": "https://example.com",
  "tags": ["Промпты", "Практика"],
  "category": "Практика",
  "emoji": "✨",
  "read_time": "5 мин",
  "accent": "#c9ff4f",
  "featured": false
}
```

Теги и количество карточек на сайте обновятся автоматически.
Цвет `accent` задаёт подсветку конкретной карточки.

## Возможности

- поиск по заголовкам, описаниям и тегам;
- фильтр по тегам (на телефоне — горизонтальная прокрутка);
- кнопка «Открыть материал» у каждой карточки;
- появление карточек при прокрутке, наклон за курсором и подсветка;
- форма подписки с валидацией и конфетти (демо, письма не отправляются);
- поддержка `prefers-reduced-motion`;
- адаптивная вёрстка для телефона, планшета и компьютера.
